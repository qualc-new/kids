# 儿童互动练习

单文件 HTML，浏览器打开即可。界面统一小汽车主题（角落车、按钮图标、马路条纹）；3～5 岁数学游戏用车当练习素材，分苹果 / 找房子玩法不变，只套同一套界面装饰。

建议从首页进入：

- [全部练习 · 入口列表](index.html)

## 怎么打开

用 Chrome / Edge / Safari 直接打开 `index.html`，或在本目录启动本地服务：

```bash
npx --yes serve .
python -m http.server 8080
```

### 分苹果

把苹果按「一人一个」分给小朋友（或盘子）。

- **看动画：** 点「分发」，苹果一轮一轮飞入盘子，分完给出算式（如 `10 ÷ 3 = 3 余 1`）。
- **自己分：** 把苹果拖进盘子，点「检查」。

### 找房子

左边是小动物和房子描述，右边是四栋不同的房子。

- 从动物拖线到房子，或先点动物再点房子。
- 连满 4 条线后点「检查」。共 3 关，房子顺序会打乱。
