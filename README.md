# 儿童互动练习

小学低年级用的两道互动练习，单文件 HTML，浏览器打开即可，无需安装和构建。

## 怎么打开

用 Chrome / Edge / Safari 直接打开对应文件，或在本目录启动本地服务：

```bash
# 任选一种
npx --yes serve .
python -m http.server 8080
```

然后访问：

- [平均分：分苹果](apple-share.html)
- [找房子：观察与匹配](find-house.html)

## 平均分：分苹果

文件：`apple-share.html`

把苹果按「一人一个」分给小朋友（或盘子），体会平均分和余数。

- **看动画：** 点「分发」，苹果一轮一轮飞入盘子，分完给出算式（如 `10 ÷ 3 = 3 余 1`）。
- **自己分：** 把苹果拖进盘子，点「检查」判断是否平均。
- 可切换题目、苹果个数、分成几份，以及「小朋友 / 盘子」两种展示。

## 找房子：观察与匹配

文件：`find-house.html`

左边是小动物和房子描述（如「红色房顶，黄色窗户」），右边是四栋不同的房子。

- **拖拽连线：** 从动物拖一条线到对应房子。
- **点击匹配：** 先点动物，再点房子。
- 连满 4 条线后点「检查」：绿线正确，红线需对照描述重连。
- 共 3 关，特征逐步增多（房顶、窗户、门、烟囱、墙色），每关房子顺序会打乱。

## 说明

- 纯前端，无接口、无依赖。
- 画面画在页面里的 Canvas 上，支持鼠标和触屏。
- 建议用较新的桌面或平板浏览器。
